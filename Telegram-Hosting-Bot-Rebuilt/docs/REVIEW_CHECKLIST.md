# قائمة مراجعة الملف قبل تشغيله

1. اقرأ جميع ملفات Python؛ لا تعتمد على نتيجة الفحص وحدها.
2. ابحث عن `eval`, `exec`, shell commands, تنزيل ملفات، تحميل ديناميكي، طلبات شبكة غير مبررة، وقراءة متغيرات البيئة.
3. ارفض المشاريع التي تحاول إدارة Docker أو استضافة بوتات أخرى إذا كانت سياسة المنصة تمنع ذلك.
4. لا تثبت `requirements.txt` من المستخدم تلقائياً.
5. اختبر على خادم تجريبي مستقل قبل الإنتاج.
6. راقب سجلات الحاوية والموارد بعد التشغيل.
7. إذا انكشف أي توكن، أبطله وأصدر بديلاً من BotFather.
