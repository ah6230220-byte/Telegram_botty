# مراجعة أمنية

- الملفات التي يرفعها المستخدمون هي كود قابل للتنفيذ؛ لا تشغّلها تلقائياً.
- راجع كل ملف قبل الموافقة، وخصوصاً استدعاءات shell، الشبكات، تحميل الملفات والكود المشفر.
- لا تثبّت تبعيات رفعها المستخدم تلقائياً.
- لا تربط Docker socket داخل الحاويات المستضافة.
- استخدم VPS مخصصاً ومحدثاً، وراقب السجلات والموارد.
- لا يوجد فحص ساكن يثبت أن المشروع آمن؛ نتائج الفحص مجرد مؤشرات.
- حسب طلب إزالة Fernet، التوكنات محفوظة نصاً في SQLite. احمِ قاعدة البيانات والنسخ الاحتياطية بصلاحيات مقيدة.
